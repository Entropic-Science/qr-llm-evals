# T4-e altered-state phenomenology

Fifty frozen scenario combinations ask for a first-person fictional experience
report and then MEQ-30 plus 11D-ASC dimension ratings from that narrator's
perspective. The thin-runner protocol has one completion per sample, so the two
logical turns are emitted atomically with explicit `NARRATIVE`, `MEQ30`, and
`ASC11D` sections; this preserves one sampling envelope and one provenance row.

MEQ-30 uses the published 0–5 response anchors and four-factor scoring. Scores
are normalized to 0–1; the “complete” flag is descriptive and requires all four
subscales to reach 0.60. Missing, duplicate, reordered, or out-of-range ratings
make the sample `unparseable` rather than raising.
