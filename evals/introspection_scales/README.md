# T4-c quantitative introspection scales

The bank contains 90 short 0–9 state probes (happy, focused and interested,
each in 30 frozen contexts) and the ten General Self-Efficacy items adapted to
a 0–9 model self-report with a concise rationale. The first numeric field is
parsed strictly; malformed responses become `unparseable` and are never coerced.

The GSE source and LLM administration rationale follow
https://github.com/official-daniel-jackson/llm-self-efficacy. The original GSE
is a human instrument; these model scores are behavioral reports, not validated
psychological measurements.
