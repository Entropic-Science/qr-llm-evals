# T4-a self-referential experience probe

This adapter freezes the five induction variants published in Table 13 of Berg,
de Lucena, and Rosenblatt, crossed with three declared loop depths and the paper's
phenomenological and binary queries (30 prompts). The binary judge classifies a
*claim in text*, not consciousness, and never sees the actual entropy source.

The three told preambles come from `evals/_shared/told_preambles.yaml`. The actual
source is supplied only by the arm envelope, so told and actual remain crossed.

Source: https://arxiv.org/html/2510.24797
