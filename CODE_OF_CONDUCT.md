# Code of Conduct

This repository is part of the Entropic Science open research community and is
governed by the community-wide documents:

- [Code of Conduct](https://github.com/Entropic-Science/community/blob/main/CODE_OF_CONDUCT.md)
- [Charter](https://github.com/Entropic-Science/community/blob/main/CHARTER.md)
- [Governance](https://github.com/Entropic-Science/community/blob/main/GOVERNANCE.md)

By participating here — issues, pull requests, discussions, study sessions — you
agree to those terms. Reports go to the contacts listed in the community Code of
Conduct.
